Criar uma senha nova

Recebemos um pedido para trocar a senha de {{ .Email }}. O botão abaixo abre a tela onde você escolhe a nova — e já entra com ela.

Escolher senha nova

Se o botão não abrir, copie este endereço no navegador:

{{ .SiteURL }}/senha?codigo={{ .TokenHash }}

O link vale uma vez só e por pouco tempo. Se não foi você que pediu, ignore este email: sua senha atual continua valendo e ninguém entrou na sua conta.
